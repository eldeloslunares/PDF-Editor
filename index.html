Cómo subir tu Editor a GitHub Pages

PASO 1: Guarda este código como un único archivo llamado index.html.
PASO 2: Entra a tu cuenta de GitHub.com, crea un repositorio nuevo (por ejemplo mi-editor-pdf) y sube el archivo index.html.
PASO 3: Ve a Settings → Pages en tu repositorio, selecciona la rama main y pulsa Save. ¡En 1 minuto tendrás tu propio enlace web gratuito para siempre!
